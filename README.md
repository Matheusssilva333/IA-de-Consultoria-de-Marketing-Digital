## Assistente de consultoria Java para crescimento digital integrado à API do Manus AI
Este projeto teve como objetivo o desenvolvimento de um agente de inteligência artificial em Java utilizando a API do Manus AI que 
atua como consultor de marketing digital para ajudar empresas a crescerem no ambiente virtual.

## Tecnologias utilizadas
- Java
- API Manus AI
- Apache Netbeans

## Funcionamento 
O usuário vai fazer uma pergunta detalhando o seu setor, função, empresa e problema a ser resolvido e o Assistente vai analisar e buscar entender o contexto da empresa e trazer respostas estratégicas para o usuário.

## Segurança
Todos dados serão protegidos e mantidos dentro da conta do usuário, respeitando as regras de LGPD.
